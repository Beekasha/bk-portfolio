01. What it does

🐢

Speed without pitch

Slow a track from 25% to 150% to catch every note — the pitch stays exactly where it was.

🎚️

Pitch without speed

Transpose ±12 semitones to match alternate tunings or sing it in your key — tempo stays put.

🔁

A–B looping

Drop a start and end point right on the waveform and loop a tricky passage until it's locked in.

📍

Section markers

Drop color-coded markers for verse, chorus, and solo, then jump between them with a keystroke.

〰️

Full waveform view

A scrollable waveform with a compact overview, live playhead, and your loop region overlaid.

🎵

Drag & drop any file

Load MP3, WAV, M4A, AAC, or FLAC. Drop it in, click the waveform to seek, and start practicing.

02. Download

macOS

Apple disk image (.dmg)
For you
Download for Mac
  1. Open the downloaded SoloTrainer.dmg.
  2. Drag SoloTrainer into your Applications folder.
  3. First launch: right-click → Open, then confirm. (macOS asks once because the app isn't notarized.)

Windows

64-bit installer (.exe)
For you
Download for Windows
  1. Run the downloaded SoloTrainer…-setup.exe.
  2. If Windows SmartScreen appears: click More info → Run anyway.
  3. Follow the installer, then launch SoloTrainer from the Start menu.

Prefer an MSI? Download the .msi installer →

Updates are built in — once installed, SoloTrainer checks for and applies new versions automatically.
